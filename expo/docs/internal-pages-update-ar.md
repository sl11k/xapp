# توثيق تغييرات هيكلة الصفحات الداخلية

## الملفات الجديدة
- `expo/styles/internalPageStyles.ts`
  - ملف أنماط مشترك للصفحات الداخلية.
  - يحتوي قواعد موحدة للهيدر الداخلي، شريط البحث، وتبويبات التصنيفات.

## الملفات التي تم تعديلها
- `expo/app/(tabs)/communities.tsx`
  - إزالة البانر العلوي.
  - اعتماد ترتيب: العنوان ثم البحث ثم التصنيفات.
  - إعادة ضبط عنصر أيقونة المجتمع لتوسيط الأيقونة بالكامل داخل الحاوية.

- `expo/app/(tabs)/marketplace.tsx`
  - إزالة البانر العلوي.
  - اعتماد ترتيب: العنوان ثم البحث ثم التصنيفات.
  - توحيد نمط التصنيفات مع الصفحة الرئيسية.

- `expo/app/knowledge.tsx`
  - إزالة البانر الترويجي العلوي.
  - توحيد نمط تبويبات الفلترة مع النمط المشترك.

- `expo/app/events.tsx`
  - إزالة بانر الفعالية القادمة.
  - توحيد نمط تبويبات الفلترة مع النمط المشترك.

- `expo/app/notifications.tsx`
  - إزالة بانر الإشعارات غير المقروءة.
  - توحيد تبويبات التصفية بصرياً مع بقية الصفحات الداخلية.
